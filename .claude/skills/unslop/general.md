# General language style rules

## Style

- STY-01 Write direct Subject-Verb-Object sentences.
- STY-02 Keep an adverb next to its verb. Shorten the object when it pushes the
  adverb to the end.
- STY-03 Never use cleft constructions, especially It-cleft,
  Wh-cleft/Pseudo-cleft and their reversed forms.
- STY-04 Name the specific thing a pronoun or pointing word stands for. "The
  loader evicts stale rows. This frees memory." → "The eviction frees memory."
- STY-05 Keep sentences and paragraphs short.
- STY-06 Never write a confession or an apology.
- STY-07 Never write an indefinite pronoun as the subject of a claim when a
  concrete alternative exists: nothing, nobody, no one, something, anything,
  everything
- STY-08 Write one fact per sentence.
- STY-09 Keep each fact in one place.
- STY-11 Never justify unless the reader asks. Evidence is not a defense.
- STY-12 State the conclusion first and the evidence after.
- STY-13 Make the actor the subject and give it a real verb.
- STY-14 Do not describe alternatives you rejected. No "X, not Y".
- STY-15 Drop the consequence clause when the first clause implies it. "The
  queue is empty, so nothing is waiting." → "The queue is empty."
- STY-16 Never write an adverb that adds no information, such as honestly or
  genuinely.
- STY-17 Never write a metaphor, such as seam, blast radius, or load-bearing.
- STY-18 Never write a verb such as carry, travel, live, earn, be for, learn,
  know, want, decide, understand, notice, realise, believe, expect, care, or
  try with a non-person subject. Keep the verb when the subject is a person.
- STY-22 Replace a periphrasis with the single word it paraphrases. Keep the
  phrase when no single word expresses it: "almost no", "no fewer than", "not
  always able to". The list is open:
  - Negation: at no point → never
  - Modality: is required to → must
  - Verb plus nominalization: makes use of → uses
  - Copula plus adjective: is dependent on → depends on
  - Connective: in order to → to
- STY-23 Never write paired correlative conjunctions.
- STY-24 Never write contact clauses. Write standard relative clauses: X a Y
  needs → X that a Y needs
- STY-25 Never cut a sentence down to a verbless fragment.
- STY-26 Never write an em dash or a semicolon.
- STY-27 Write negative auxiliaries in full: does not, has not, will not.
